# 🌤️ Weather Web App

Веб-приложение для отображения текущей погоды и прогноза на 5 дней.

## 🚀 Функции

### Главная страница (/)
- Текущая температура
- Ощущаемая температура
- Влажность воздуха
- Атмосферное давление
- Скорость ветра
- Время восхода и захода солнца
- Автообновление каждые 15 минут
- Автоматическое переключение темы (день/ночь)

### Прогноз на неделю (/forecast)
- Прогноз на 5 дней
- Температура днём
- Иконка погоды
- Влажность
- Скорость ветра
- Адаптивный дизайн

## 🛠 Технологии

- **Backend:** Flask (Python)
- **Frontend:** HTML, CSS, JavaScript
- **API:** OpenWeatherMap
- **Шрифты:** Google Fonts (Roboto)

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Rom2555/weather_web.git
cd weather_web
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` из `.env.example`:
```bash
cp .env.example .env
```

5. Запустите приложение:
```bash
python app.py
```

6. Откройте в браузере: http://127.0.0.1:5000

## 🐳 Docker

Приложение также можно запустить в Docker:

```bash
# Скопируйте .env.example в .env
cp .env.example .env
# Отредактируйте .env с вашими настройками

docker build -t weather_web .
docker run --env-file .env -p 5000:5000 weather_web
```

## 🏗 Архитектура

Приложение построено по принципу клиент-серверной архитектуры:

- **Backend (Flask)**: Обрабатывает запросы к OpenWeatherMap API, кеширует данные и предоставляет RESTful endpoints
- **Frontend (HTML/CSS/JS)**: Отображает данные в пользовательском интерфейсе с анимациями и адаптивным дизайном
- **API взаимодействие**: Все запросы к погодному сервису идут через backend для скрытия API ключа и реализации кеширования
- **Docker контейнеризация**: Приложение упаковано в контейнеры для легкого развертывания
- **Nginx как reverse proxy**: Обеспечивает обслуживание статических файлов и балансировку нагрузки

## 🔌 API Endpoints

### Публичные endpoints:
- `GET /` - Главная страница с текущей погодой
- `GET /forecast` - Страница с прогнозом на 5 дней
- `GET /api/version` - Возвращает текущую версию приложения (для cache busting)
- `GET /api/weather` - Текущая погода в JSON формате
- `GET /api/forecast` - Прогноз на 5 дней в JSON формате
- `GET /health` - Healthcheck endpoint для Docker

### Параметры API:
Все API endpoints возвращают данные в формате JSON с полями:
- `city`: Название города (жестко задано как "Мытищи")
- Остальные поля зависят от типа запроса (см. код для деталей)

## ⚙️ Переменные окружения

Приложение использует следующие переменные окружения (задаются в `.env` файле):

### Обязательные:
- `API_KEY` - Ключ для доступа к OpenWeatherMap API
- `LAT` - Широта местоположения (например, 55.917460 для Мытищ)
- `LON` - Долгота местоположения (например, 37.727200 для Мытищ)

### Опциональные с значениями по умолчанию:
- `API_TIMEOUT` - Таймаут запросов к API в секундах (по умолчанию: 10)
- `CACHE_TTL` - Время жизни кеша в секундах (по умолчанию: 300 - 5 минут)

## 🔧 Troubleshooting

### Проблемы с API ключом:
- Убедитесь, что вы скопировали правильный API ключ из вашего аккаунта OpenWeatherMap
- Проверьте, что ключ не содержит лишних пробелов или символов
- Убедитесь, что ваш тарифный план позволяет делать запросы к текущей погоде и прогнозу

### Проблемы с координатами:
- Координаты должны быть в десятичном формате (например, 55.917460, не 55°55'02.9"N)
- Широта должна быть в диапазоне от -90 до 90
- Долгота должна быть в диапазоне от -180 до 180

### Проблемы с Docker:
- Если контейнер не запускается, проверьте логи: `docker logs <container_name>`
- Убедитесь, что порт 5000 не занят другим процессом
- Для проблем с healthcheck проверьте доступность endpoint `/health`

### Проблемы с производительностью:
- Приложение использует кеширование для уменьшения количества запросов к API
- Если данные не обновляются, проверьте значение CACHE_TTL в коде
- При частых ошибках API проверьте ваше интернет-соединение и статус OpenWeatherMap сервиса
